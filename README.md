<h1>Pascal to C++ Translator</h1>
<h2>Транслятор с языка Pascal на язык  C++</h2>
<p>Перед началом работы необходимо установить библиотеку streamlit для работы интерфейса</p>
<p>pip install streamlit</p>
<p>Для запуска графического интерфейса необходимо написать в терминал streamlit run app.py</p>
<p>В левое окно необходимо ввести код на языке Pascal и нажать кнопку "Запустить компиляцию. В правом окне будет код на языке C++. В нижнем окне будет выведено сообщение об успешной компиляции или об ошибке и ее описание."</p>
